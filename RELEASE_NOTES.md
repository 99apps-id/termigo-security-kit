# Termigo Security Kit v0.1.0

## What's Included
- SAST scanner (semgrep, bandit, gosec, eslint-plugin-security)
- Dependency audit (osv-scanner, npm audit, pip audit, cargo audit, govulncheck)
- AV/Malware/Adware scanner (ClamAV, Windows Defender, YARA)
- YARA rules for adware-only scanning
- Full documentation with installation and how-to guides

## Files
- termigo-security-kit.zip
- termigo-security-kit.zip.sha256

## Installation
1. Download termigo-security-kit.zip
2. Open Termigo -> Extensions -> Install from File
3. Verify checksum with termigo-security-kit.zip.sha256

See README.md for full documentation.
